How to confirm Error 153

  1. Open this page on your Cloudflare public domain, not as a local file.
  2. Click Test standard embed. If it fails, try privacy-enhanced embed.
  3. On desktop, open DevTools → Network, select the request to youtube.com/embed/GyZOfmaDvRU, and inspect Request Headers → Referer. It should show your Cloudflare site origin.
  4. If Referer is present and it still fails, confirm the stream is public/unlisted and has Allow embedding enabled in YouTube Studio. Also test without privacy/ad-blocking browser extensions.

Note: iframe onload means the frame loaded, not that playback succeeded. This page cannot read cross-origin YouTube's playback status.
